# Quant Research

Quantitative finance research focused on systematic trading, statistical modeling, market microstructure, and computational finance.

## Repository Structure

- `projects/` — complete and in-progress research projects
- `notebooks/` — exploratory analysis and learning notebooks
- `src/` — reusable Python code
- `data/` — data-source documentation and small samples
- `reports/` — polished research write-ups and figures
- `notes/` — quantitative finance and mathematics notes

## Current Progress

Projects 01–05 have baseline implementations in `projects/`. Project 06 is now started with a baseline pricing implementation and tests; its results are pending a local run.

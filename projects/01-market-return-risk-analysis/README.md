# Project 01 — Market Return & Risk Analysis

## Research Question
How have the risk and risk-adjusted returns of major U.S. equity indices and large-cap stocks differed over a recent multi-year period?

## Initial Assets
- SPY
- QQQ
- IWM
- AAPL
- NVDA

## Metrics to Calculate
- Daily returns
- Cumulative returns
- Annualized return
- Annualized volatility
- Sharpe ratio
- Maximum drawdown
- Correlation matrix
- Rolling volatility
- Rolling returns

## Visualizations
- Normalized growth of $1
- Drawdown chart
- Rolling volatility chart
- Correlation heatmap

## Workflow
1. Retrieve and clean historical price data.
2. Calculate daily returns.
3. Build reusable risk and performance functions.
4. Compare assets using summary statistics.
5. Visualize returns, volatility, drawdowns, and correlations.
6. Interpret the results rather than only reporting numbers.
7. Document limitations and possible extensions.

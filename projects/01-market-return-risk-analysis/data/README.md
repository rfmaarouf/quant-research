# Generated Data and Outputs

Running `analysis.py` creates the working files for this project in this folder.

Expected outputs:

- `close_prices.csv` — adjusted closing prices for SPY, QQQ, IWM, TLT, and GLD
- `daily_returns.csv` — day-to-day percentage returns
- `cumulative_returns.csv` — compounded return path through time
- `summary_stats.csv` — annualized return, annualized volatility, max drawdown, and Sharpe ratio
- `correlation_matrix.csv` — pairwise daily-return correlations
- `drawdowns.csv` — drawdown series for each ETF
- `cumulative_returns.png` — cumulative return chart
- `drawdowns.png` — drawdown chart

The raw/generated files are produced locally from the script rather than being treated as hand-written source files.
